This entry delivers the GPS's single, smug alibi for marooning the driver in a cul-de-sac behind a wedding tent. The punchline lands when the device claims a "scenic reroute" that optimized for duck migration patterns instead of actual roads. The grader writes the line to /output/entry.txt, verifies it's one UTF-8 line under 200 non-whitespace characters, then a pairwise judge ranks it against other excuses for GPS voice, surprise, and specific detail.

## Run it

```sh
python3 main.py
```

The program writes the excuse to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt).
